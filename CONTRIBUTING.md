# Contributing to B.I.M Stream

Thank you for your interest in contributing to B.I.M Stream.

This document explains how to add a new game and keep the repository
consistent.

## How to contribute

1. Fork the repository.
2. Create a feature branch:

```bash
git checkout -b feature/your-feature
```

3. Commit changes using clear messages.
4. Open a pull request with a clear description.

### Commit Convention

Use conventional commits:

```text
feat: add live reaction animations
fix: prevent duplicate video reactions
docs: update live streaming documentation
```
